---
name: plan-feature
description: Turn a feature request into a reviewed plan before any code is written.
---
1. Restate the request in one sentence and list what is out of scope. If something essential is unclear, ask one question (ask_user) before going on.
2. Investigate: find where similar features live, the data they touch, the tests around them. Read, do not edit.
3. Write the plan with claims tagged fact, inference or assumption, each with evidence. Steps are small and each leaves the project working. Include a validation command.
4. Name the risks and how each step is undone. Do not start building until the plan is approved.
