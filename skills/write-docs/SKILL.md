---
name: write-docs
description: Write or update README and docs so a newcomer can use the project in five minutes.
---
1. Read the code and the existing docs. Run the install and start commands yourself (read-only checks first) so every command in the docs is one you saw work.
2. Structure: what it is in one sentence, install, the shortest working example, the main options, troubleshooting. Put the most common path first.
3. Keep sentences short and concrete. No marketing words. Show real output where it helps.
4. Say plainly what is untested or unfinished instead of leaving it out.
5. Plan one step per file. Check that every file path, command and flag you wrote exists (search for it).
